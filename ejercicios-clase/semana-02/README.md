# Ejercicio de clase 02 -Configuración del entorno de trabajo

- Se creo un entorno virtual de python utilizando **py -m venv venve**
- El entorno se activo en windows con **.\venv\Scripts\Activate.ps1**
- Se verifico la activavión mediante el prefijo venv en la terminal
- Se instalo la libreria matplotlib dentro del entorno virtual
- Las dependencias se registraron en un archivo requirement a traves de **pip freeze > requirements.txt**
- Se desactivo y elimino el entorno y para reproducir el entorno, se debe crear un nuevo entorno con py -m venv venv
- Luego se activa el entorno y se ejecuta pip install -r requirements.txt.
- La carpeta venv/ está incluida en .gitignore y no se versiona.
